# Лабораторная №2

Реализовать подтверждение кода отпраленного на почту, используя smtp сервер mail, и веб фреймворк Golang Fiber

###     Требования

    -  Реализовать 2 api, методами Get и Post
    -  Get - отправляет код, а пост принимает код и отправляет статус валидности кода


    Fiber - go get -u github.com/gofiber/fiber/v3    
    go.mail - go get -u gopkg.in/mail.v2
